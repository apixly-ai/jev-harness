# Jev Harness

Jev-native agent loops with registered tools, bounded parameter choices, explicit context,
and independent completion checks. AI agents write a task script; Jev selects the next
program-owned call; the runtime executes, observes and repeats.

Independent community project by Apixly. Not an official TypeSafe AI product.

Implementation and acceptance are in progress. Browser and desktop support will be
published with specific reproducible cases, real model usage and scope limitations.
No production or benchmark claims are made by this initial bootstrap.
